# InsurAgent

סוכן AI שמכין תביעות להחזרי ביטוח בריאות עבור אנשים פרטיים. המשתמש מספר איזה טיפול עשה ואיזה ביטוח יש לו, והסוכן:

1. מבין את התביעה ובונה רשימת מסמכים נדרשים (מתוך מאגר תבניות לפי חברה וסוג תביעה).
2. אוסף בעצמו מה שאפשר: מסמכים שהמשתמש העלה, מסמכים מתביעות קודמות (ת"ז, אישור בנק), ובהמשך גם מהמייל.
3. מה שלא אפשר, הופך למשימה למשתמש (לצלם, לחתום, לשלוח מייל שכבר הוכן) ורודף אחריו עם תזכורות.
4. מכין טיוטות מייל, למשל בקשת פירוט טיפולים מהמרפאה.
5. בסוף בונה חבילת הגשה: PDF עם טופס פרטי תביעה חתום וכל המסמכים, יחד עם הוראות הגשה. המשתמש מגיש בעצמו.

## הרצה

דרישות: Node 22.

```bash
npm install
cp server/.env.example server/.env   # ולהכניס ANTHROPIC_API_KEY
npm run dev                          # שרת על 8787 + אתר על 5173
```

פותחים את http://localhost:5173 (בנייד: הכתובת ברשת המקומית ש-Vite מדפיס).

## מבנה

```
server/                 Node + Hono + SQLite (node:sqlite)
  src/agent/            לולאת הסוכן (Claude Opus 5.5 + tool use), הכלים וה-system prompt
  src/claims.ts         משימות, תזכורות ומצב התביעה שהסוכן רואה בכל תור
  src/pdf.ts            בניית חבילת ההגשה (כולל טקסט עברי RTL)
  src/reminders.ts      לולאת התזכורות (כרגע הדפסה לקונסול)
  knowledge/            תבניות דרישות לפי חברה וסוג תביעה (JSON)
web/                    React + Vite, RTL, מותאם לנייד (PWA)
```

## איך הסוכן עובד

- כל תביעה היא שיחה. ההיסטוריה נשמרת ב-`agent_turns` ונשלחת למודל כמו שהיא, בלי עריכה.
- בכל תור נשלח למודל `<claim_state>` עם מצב התביעה העדכני: דרישות, משימות, מסמכים ומיילים.
- פעולות של המשתמש במסכים (העלאה, חתימה, "שלחתי") מגיעות לסוכן כ-`<app_event>`, והוא ממשיך משם.
- התזכורות לא עוברות דרך המודל: יש לוח זמנים קבוע (1, 3, 7 ימים ואז כל שבוע) וכל תזכורת מקשרת ישר למשימה.
- ה-API מוגדר עם fallback אוטומטי בצד השרת (`fallbacks: "default"`): אם המודל דוחה בקשה מסיבות בטיחות, הבקשה רצה שוב על מודל חלופי.

## מה עוד לא קיים

- **התחברות אמיתית:** כרגע כניסת פיתוח עם מייל בלבד. צריך Google Sign-In או קוד ב-SMS.
- **חיבור Gmail:** הכלי `search_email` מחזיר "לא מחובר". צריך OAuth עם הרשאת קריאה בלבד, ו-Gmail Drafts כדי לצרף קבצים למיילים (mailto לא תומך בקבצים מצורפים).
- **ערוצי תזכורת:** מייל, WhatsApp ו-Web Push. כרגע התזכורות רק מודפסות לקונסול.
- **מאגר ידע מאומת:** התבניות ב-`knowledge/` הן טיוטות (`verified: false`). צריך לאמת אותן מול הטפסים וההנחיות של כל חברה, ובהמשך למלא את טופס התביעה המקורי של החברה במקום טופס הפרטים הכללי.
- **אבטחה ופרטיות:** מידע רפואי ופרטי בנק דורשים הצפנה, מדיניות שמירה וגיבוי לפני שימוש אמיתי.
